
# michifehr.ch – Persönliche Portfolio-Website

## Überblick

Dies ist meine persönliche Portfolio-Website, auf der ich meinen beruflichen Werdegang, meine Fähigkeiten, Projekte und Erfahrungen übersichtlich darstelle. Die Seite dient als zentrale Plattform zur Präsentation meiner Person und meiner Arbeit.

🌐 Website: [https://www.michifehr.ch](https://www.michifehr.ch)

----------

## Zweck der Website

Die Website wurde erstellt, um:

-   meinen Lebenslauf und beruflichen Werdegang strukturiert darzustellen
-   Projekte, Fähigkeiten und Zertifikate zu präsentieren
-   eine einfache Kontaktmöglichkeit bereitzustellen
-   eine professionelle Online-Präsenz aufzubauen

----------

## Funktionen

-   Responsives Design (Desktop, Tablet, Mobile)
-   Persönliche Intro-Seite
-   Lebenslauf- und Erfahrungsbereich
-   Projekt- und Zertifikatsübersicht
-   Kontaktformular
-   Moderne, benutzerfreundliche Navigation

----------

## Verwendete Technologien

-   HTML5
-   CSS3
-   JavaScript
